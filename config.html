The same uploaded logo is used as the top-left ticket logo and as the large faint watermark. A background image is optional. These files are stored in the Drive folder created by the new Apps Script project.

Google Form

The Apps Script function createEventConfigForm() creates the dedicated Google Form connected to this new spreadsheet. The form supports event text, groups, tiers, capacity and status. Branding images stay on this page so uploads work reliably.

After running createEventConfigForm(), copy the published Form URL into FORM_URL in site-config.js if you want a direct button here.
Event branding is isolated by Event ID.
